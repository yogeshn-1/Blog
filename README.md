# Bloggers Haven

Welcome to my personal blogging website Bloggers haven! This platform allows users to register, log in, create blog posts, and upload files to their posts.

## Features

1. **User Authentication**: Users can register and log in to the platform.
2. **Blog Posts**: Authenticated users can read and publish blog posts.
3. **File Upload**: Users can upload files to their blog posts.
4. **Backend Support**: Utilizing Appwrite for backend services including authentication and data storage.

## Technology Stack

**Frontend**: HTML,CSS,Javascript,React <br>
**Backend**: Appwrite <br>
**Database**: Appwrite's built-in database services <br>

_Project is live [here](https://bloggershaven.vercel.app/)_
